# 🗡️ Joda’s Adventure

**Created by:** Koda Dearing & Joshua Masoumi  
**Engine:** [Godot Engine 4.x](https://godotengine.org/)  
**Language:** GDScript  
**Date:** April 2025  

---

## 🎮 Overview
**Joda’s Adventure** is a 2D action-platformer built in the Godot Engine.  
You play as **Joda**, a brave hero exploring a world filled with enemies, obstacles, and secrets.  
The game was designed as a final project to demonstrate mastery of GDScript, level design, and UI systems.

---

## 🧩 Features
- Custom player controller with jump, attack, and movement logic  
- Enemy AI with patrol and detection behaviors  
- Scene-based level system (main scene, menus, and game over screens)  
- Global game manager for score and state tracking  
- Simple and clean pixel-art visuals  
- Fully playable from start menu to game over  

---

## 🕹️ How to Play
1. **Clone or download** this repository:  
   ```bash
   git clone https://github.com/DearingK1121/jodas-adventure.git
   ```
2. Open the project in **Godot 4.x**.  
3. Run `main.tscn` from the Godot editor.  
4. Use the following controls:
   - **Arrow keys / A, D** → Move  
   - **Space** → Jump  
   - **F** → Attack  
   - **Esc** → Pause / Menu
